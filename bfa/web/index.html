              1. Cấu Trúc Dữ Liệu BFA Trả Về (Response Schema)
            

            
Mọi API của BFA đều trả về định dạng JSON chuẩn hóa, bạn hãy đọc trường data tương ứng:

            
{
  "status": "SUCCESS", // hoặc "ERROR"
  "data": {
    "records": [...],   // Khi gọi find_all() hoặc query()
    "record": {...},    // Khi gọi find_by_id(), insert(), update()
    "deleted_id": 1     // Khi gọi delete()
  },
  "error": "Thông báo lỗi nếu status == ERROR"
}

            

              • Lấy danh sách: const list = res.data.records;

              • Lấy 1 bản ghi: const item = res.data.record;
            

          


          
          

            

              
              2. Cấu Hình Địa Chỉ IP (Base URL) Chuẩn Từng Nền Tảng
            

            
Nếu chạy trên máy ảo điện thoại hoặc điện thoại thật, bạn cần đổi địa chỉ IP như sau:

            

              
                

                  Môi Trường Client
                  Địa Chỉ Base URL Phải Dùng
                

              
              
                

                  Web React / Vue / Node
                  http://127.0.0.1:8080
                

                

                  Máy Ảo Android (Emulator)
                  http://10.0.2.2:8080
                

                

                  Máy Ảo iOS (Simulator)
                  http://127.0.0.1:8080
                

                

                  Điện Thoại Thật (Cùng Wi-Fi)
                  http://<IP_LAN_MÁY_TÍNH>:8080

Sơ Đồ Luồng Hoạt Động & Kết Nối Thời Gian Thực

          
Trực quan hóa luồng dữ liệu di chuyển từ Ứng dụng Client qua Cổng Gateway, Runtime, Bảng Dịch Vụ và Cơ Sở Dữ Liệu.

        

        

          
          
        

      


      
      

        
        
        

          
          
          

            

              TRẠM 1: CLIENT
              ONLINE
            

            

              
              Ứng Dụng Phía Khách
            

            
Web (React / Vue), Mobile App (Flutter / iOS / Android) gửi gói tin HTTP JSON Payload.

            

              POST /api/<bảng>/<thao_tác>
            

          


          
          

            

              TRẠM 2: GATEWAY
              CỔNG :8080
            

            

              
              Cổng Mạng BFA Gateway
            

            
Tiếp nhận kết nối TCP/HTTP, giải mã JSON và định tuyến luồng mạng tới Runtime.

            

              JSONDecoder + Router
            

          


          
          

            

              TRẠM 3: RUNTIME
              0 DỊCH VỤ
            

            

              
              Lõi Runtime & Dịch Vụ
            

            
Xác thực dữ liệu (Validation Schema) và điều phối các hàm CRUD / Nghiệp vụ.

            

              
            

          


          
          

            

              TRẠM 4: STORAGE
              SQLITE
            

            

              
              Cơ Sở Dữ Liệu
            

            
Đọc & Ghi dữ liệu thực tế: Lưu trữ bảng, chỉ mục và trạng thái giao dịch.

            

              SQLite Storage (bfa_database.db)
