Tài Liệu Hướng Dẫn Sử Dụng Backend for All

Hướng dẫn chi tiết từ căn bản đến nâng cao cách xây dựng, vận hành và kết nối ứng dụng Frontend vào cổng dịch vụ backend tự động BFA.

1.1 Tổng quan về Backend for All (BFA)

Backend for All (BFA) là nền tảng API gateway và động cơ sinh dịch vụ backend tự động. Mục tiêu cốt lõi của BFA là giúp lập trình viên Frontend, Mobile và Fullstack có ngay một hệ thống Backend hoàn chỉnh mà không cần tốn hàng tuần viết lại các mã nguồn CRUD lặp đi lặp lại.

Triết lý không sở hữu cơ sở dữ liệu: BFA không ép buộc người dùng phải sử dụng một loại cơ sở dữ liệu nhất định. Bạn có thể cắm BFA vào bất kỳ hệ quản trị CSDL nào (PostgreSQL, MySQL, SQLite, MongoDB, SQL Server...) và BFA sẽ tự động phát sinh toàn bộ API tương ứng.

1.2 Mô hình kiến trúc LEGO độc lập

BFA được xây dựng theo các tầng module phân tách rành mạch:

[Ứng Dụng Client (React, Vue, Flutter, iOS, Android, Python)]
                         │ (HTTP POST /api//)
                         ▼
                [HTTP Transport :8080]
                         │ (Giải mã JSON Payload)
                         ▼
                   [BFA Runtime]
                         │ (Định tuyến Service & Kiểm tra Schema)
                         ▼
            [Tự Động Sinh CRUD & Nghiệp Vụ]
                         │ (Giao tiếp qua BaseStorage)
                         ▼
       [Cơ Sở Dữ Liệu Thật (Postgres / MySQL / SQLite / Mongo)]

2.2 Kích hoạt bản thiết kế 1-Click

Tại tab 100 Kiến Trúc Mẫu trên BFA Studio:

  1. Nhập từ khóa cần tìm (Ví dụ: gọi xe, tiền điện tử, khách sạn).
  2. Bấm nút Khởi Chạy Hệ Thống trên thẻ kiến trúc tương ứng.
  3. Toàn bộ cấu trúc bảng, các ràng buộc và dữ liệu mẫu thực tế sẽ được cấp phát ngay lập tức vào cơ sở dữ liệu.

3.1 Quy trình kết nối Cơ Sở Dữ Liệu 3 Bước

BFA giải quyết hoàn toàn sự bối rối của người dùng bằng quy trình 3 bước rõ ràng:

Bước 1: Chọn CSDL & Điền Thông Số
Chọn 1 trong 10 loại CSDL và nhập Host, Port, User, Mật khẩu $\rightarrow$ Bấm Kiểm Tra Kết Nối CSDL.
Bước 2: Khai Báo Bảng Dữ Liệu
Bấm nút Tự Động Quét Bảng Trong CSDL để BFA tự động đọc các bảng hiện có, hoặc tự nhập danh sách tên bảng (ví dụ: users, products, orders).
Bước 3: Kích Hoạt Sinh Toàn Bộ API
Bấm Kích Hoạt Cơ Sở Dữ Liệu & Sinh Toàn Bộ API $\rightarrow$ BFA lưu cấu hình, kết nối CSDL và tự động mở toàn bộ các endpoint CRUD!

4.1 6 Thao tác CRUD chuẩn hóa

Với mỗi bảng dữ liệu, BFA tự động sinh 6 thao tác chuẩn hóa sẵn sàng phục vụ:

  • find_all: Lấy danh sách bản ghi (hỗ trợ phân trang limit, offset).
  • find_by_id: Lấy thông tin chi tiết một bản ghi theo khóa chính id.
  • insert: Thêm mới bản ghi vào cơ sở dữ liệu.
  • update: Cập nhật thông tin bản ghi theo id.
  • delete: Xóa bản ghi khỏi hệ thống.
  • query: Truy vấn lọc nâng cao theo các điều kiện lọc linh hoạt.

5.0 Hợp Đồng Nhất Thể Duy Nhất (Universal Single Contract)

Để tối giản hóa tối đa, mọi ngôn ngữ (JavaScript, Android Kotlin, Flutter Dart, Python, Swift, PHP, cURL) chỉ cần gọi qua ĐÚNG 1 ĐIỂM CUỐI DUY NHẤT:

POST http://127.0.0.1:8080/api/bfa/call

Cấu trúc gói tin gửi lên (Request Envelope) cố định:

{
  "service": "users",     // Tên bảng (hoặc để trống nếu dùng snapshot)
  "action": "find_all",   // find_all, find_by_id, insert, update, delete, query, snapshot, batch
  "payload": { "limit": 10 }
}

5.1 Tích hợp JavaScript & React

Sử dụng Fetch API chuẩn để kết nối từ React, Next.js, Vue hoặc Node.js:

// Lấy danh sách sản phẩm từ BFA
const phanHoi = await fetch("http://127.0.0.1:8080/api/products/find_all", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ limit: 10 })
});

const ketQua = await phanHoi.json();
console.log("Dữ liệu sản phẩm:", ketQua.data.records);

5.2 Tích hợp Android Native (Kotlin + Retrofit 2)

Để ứng dụng Android kết nối đến BFA Backend mà không gặp lỗi Network Security:

  1. Khai báo trong AndroidManifest.xml: <uses-permission android:name="android.permission.INTERNET" />
  2. Thêm thuộc tính: android:usesCleartextTraffic="true" vào thẻ <application>.
  3. Địa chỉ kết nối máy ảo Android Emulator: http://10.0.2.2:8080/
// Retrofit Interface cho Android Kotlin
interface BfaApiService {
    @POST("api/products/find_all")
    suspend fun getProducts(@Body req: Map<String, Any> = mapOf("limit" to 10)): Response<BfaResponse<RecordsData>>
}

object BfaApiClient {
    private const val BASE_URL = "http://10.0.2.2:8080/"
    val api: BfaApiService by lazy {
        Retrofit.Builder()
            .baseUrl(BASE_URL)
            .addConverterFactory(GsonConverterFactory.create())
            .build()
            .create(BfaApiService::class.java)
    }
}

5.3 Tích hợp Flutter & Mobile App (iOS / Android) 

import 'dart:convert';
import 'package:http/http.dart' as http;

Future<void> layDanhSachSanPham() async {
  // Chú ý: Dùng 10.0.2.2 khi chạy máy ảo Android Emulator
  final uri = Uri.parse('http://10.0.2.2:8080/api/products/find_all');
  final phanHoi = await http.post(
    uri,
    headers: {'Content-Type': 'application/json'},
    body: jsonEncode({'limit': 10}),
  );

  if (phanHoi.statusCode == 200) {
    final ketQua = jsonDecode(phanHoi.body);
    print('Danh sách sản phẩm: \${ketQua["data"]["records"]}');
  }
}

6.1 Hướng dẫn đóng góp cho cộng đồng

BFA là dự án mã nguồn mở hướng tới cộng đồng. Để bổ sung các bản thiết kế kiến trúc số 101, 102...:

  1. Mở file bfa/catalog/registry.py trong mã nguồn.
  2. Khai báo thông số hệ thống vào từ điển BLUEPRINT_CATALOG.
  3. Tạo Pull Request trên GitHub để cộng đồng cùng đánh giá và đưa vào phiên bản chính thức.
